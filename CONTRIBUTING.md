# Contributing

Thanks for helping! A few ground rules that come from the design:

- **Deliberate non-features** — please don't PR these without discussion:
  custom/vanity addresses, sending mail, account registration, per-mailbox
  quotas. They are out of scope by decision, not by omission.
- Run `npm test` before opening a PR; add tests for new core logic in
  `src/lib/`.
- Keep runtime dependencies minimal and check their licenses are
  AGPL-compatible.
- By contributing, you agree your contribution is licensed under
  AGPL-3.0-only, the project's license.
